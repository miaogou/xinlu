Linux 驱动学习中的一个小 demo，作用是开发正点原子 iMX6ULL 中的 KEY0 这个按键。

## 有关程序的编译

该项目的编译方式采用交叉编译，相关的编译规则请参考 [`Makefile`](./Makefile)。

为什么采取交叉编译？因为在 iMX6ULL 板端进行编译的时间太长。

直接在 PC 端模拟板端的编译环境，将该 `c` 文件编译为能直接在板端运行的 `ko` 文件后，直接将 `ko` 文件传输到板端进行运行。

## 有关编译完成之后的运行

按照目前的理解，该代码的后续应该按照以下顺序进行升级：

1. **当前状态**：单进程，单设备，只涉及驱动层代码，不涉及应用层代码，申请与调用 `gpio18` 只在代码中写死，不涉及设备树 `dts`。
2. **下一步开发目标**：将该代码中写死的 `gpio18` 的申请与调用优化为：设备树中完成对 `gpio18` 的申请与调用，再在代码中引用设备树。
